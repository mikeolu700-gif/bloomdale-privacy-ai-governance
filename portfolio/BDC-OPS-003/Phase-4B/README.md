# Phase 4B: Website Cookie Scanning

The controlled baseline HTML fixture is included in this folder. It intentionally has no analytics or advertising trackers, and it does not implement consent enforcement.

The draft Word methodology `BDC-OPS-003_Phase4B_Website_Cookie_Scanning_Methodology_DRAFT_v1.0.docx` is prepared locally but has not yet been uploaded to this folder. Browser scanning and GPC enforcement testing have not been completed.
