# Phase 3B | Consent Banner, Opt-In/Opt-Out and Preference Center

**Current consolidated prototype:** [`BDC-OPS-003_Consent_Prototype_v1.1.html`](BDC-OPS-003_Consent_Prototype_v1.1.html)

This self-contained **synthetic** HTML prototype illustrates regional notice/banner treatments, Accept/Reject/Manage choices, granular preference controls, withdrawal, GPC and California opt-out UI. It uses reserved `.invalid` mock destinations to make attempted tracker requests observable in browser testing; these are not production vendors. The v1.1 case study reports 15 passing prototype tests, supported by `../Phase-4B/evidence/` and `../Phase-4B/tests/`. Those tests have not been rerun as part of this packaging step.

**Not production verified:** no real consent platform, real tracking vendors, downstream suppression, or Meridian deployment. Browser GPC and regional routing were simulated in the automated test suite. The previously planned Phase 3B v1.0 Word specification and HTML draft are not part of the supplied v1.1 package; this README does not claim they were uploaded.
